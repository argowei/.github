# Argowei on GitHub

This repository defines the public [organization profile](profile/README.md) and shared contribution files for Argowei. The application lives in [argowei/argowei](https://github.com/argowei/argowei).

## Shared defaults

| File | Purpose |
| --- | --- |
| [Issue forms](.github/ISSUE_TEMPLATE) | Guided bug reports and feature requests |
| [Pull request template](PULL_REQUEST_TEMPLATE.md) | Summary, verification, and impact for proposed changes |
| [Contributing guide](CONTRIBUTING.md) | How to propose and check changes |
| [Security policy](SECURITY.md) | How to report a vulnerability without public disclosure |
| [Support guide](SUPPORT.md) | Where to get help |

GitHub uses these as organization defaults when a repository does not define its own equivalent file. This repository must be public for the defaults to apply. Issue forms live in `.github/ISSUE_TEMPLATE` **inside this repository**, which is itself named `.github`. The forms do not assign labels, so they work in repositories with different label sets.

## Organization profile

The public profile is rendered from [`profile/README.md`](profile/README.md) when this repository is public. For a consistent appearance, use [the owl image](assets/argowei-owl.png) as the organization avatar, set the description to **Self-hosted network intelligence for homelabs**, and pin [argowei/argowei](https://github.com/argowei/argowei).
