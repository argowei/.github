# Security policy

Argowei is in early development. There is no formal release or guaranteed support window yet.

Please do not disclose a sensitive vulnerability in a public issue. If GitHub's **Report a vulnerability** option is available in the affected repository's Security tab, use it to send a private report. If it is unavailable, open an issue asking for a private reporting channel without including vulnerability details.

Include the affected version or commit, impact, and steps to reproduce. Ordinary bugs and feature requests belong in the public issue tracker.
